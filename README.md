# GDPSnode
Project is a work-in-progress! If you can see this, the project is still unfinished. Currently porting over endpoints from GMDPrivateServer (PHP) over to GDPSnode (node.js)!
GDPSnode is a **full, working replacement** to [*GMDPrivateServer*](https://github.com/cvolton/gmdprivateserver) written **entirely from scratch** with the help of the [gd-docs](https://github.com/rifct/gd-docs) (also at [boomlings.dev](https://boomlings.dev/)).
With **easy deployment and future-proofing** in mind, GDPSnode was made to *entirely replace* old Apache/nginx dependent (web)servers for an elegant **node.js + express + better-sqlite3 stack**. Everything is *fully tested* before any updates are made, ensuring a satisfying experience for the sysadmin.

GDPSnode is **FULLY compatible** with Geometry Dash as-is since it perfectly mimics the original PHP servers (with php extension endpoints) and also supports [GDPS Switcher](https://geode-sdk.org/mods/km7dev.gdps-switcher)'s MOTD and icon system for flexibility.

Reminder! GDPSnode is still a work-in-progress, many endpoints are still missing, but with time, we'll have fully ported everything through. I appreciate your patience and interest ❤️
